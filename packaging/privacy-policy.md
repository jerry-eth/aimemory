# AI 内存管家隐私政策（初稿）

生效日期：2026 年 8 月 9 日

## 1. 概述

AI 内存管家是 Windows 桌面工具，用于显示本机内存与进程状态，并根据用户明确操作执行内存清理、文件清理或进程终止。软件不提供云端账户，不内置遥测服务，不出售用户数据。

## 2. 大模型数据传输

只有当用户配置并启用大模型档案，且主动点击分析或发送对话时，软件才会把完成请求所需的最小数据发送到用户选择的 API 端点。可能包含：

- 当前内存占用摘要；
- 进程名称、PID、路径和工作集大小；
- 用户输入的对话内容；
- 分析报告和有限的对话历史。

数据只发送到用户配置的 Base URL（例如用户自己的 OpenAI 兼容服务或本机 Ollama），软件不会把这些数据转发到开发者服务器。

## 3. API Key 与本地数据

API Key 保存在本机应用数据目录，并使用 Windows DPAPI 保护。设置、白名单、黑名单、提示词、分析缓存和清理历史默认保存在本机，不会自动上传。

用户可以通过删除应用数据目录清除本地配置、缓存和历史；删除前请先关闭软件。

## 4. 系统权限与危险操作

深度清理和部分进程操作可能需要管理员权限。软件会在执行会改变系统状态的操作前显示确认界面。进程终止会显示未保存数据风险；用户可以取消操作。软件不会自动终止系统关键进程、前台保护进程或白名单进程。

## 5. 第三方服务

如果用户配置第三方大模型服务，数据处理同时受该服务提供商的隐私政策和服务条款约束。用户应确认 Base URL、API Key 和服务商的数据留存策略。
