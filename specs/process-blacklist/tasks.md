# 黑名单与对话式智能分析实施计划

- [x] 1. 扩展配置模型与本地化
  - 在 `AppSettings` 增加黑名单进程列表和自动终止开关。
  - 增加中英文黑名单、报告、对话、执行确认文案。
  - _Requirement: 1, 2, 4, 5_

- [x] 2. 实现黑名单服务
  - 新增黑名单标准化、增删、快照、持久化服务。
  - 拒绝系统关键进程、自身进程和防误杀进程加入。
  - 增加冲突和最近动作结果模型。
  - _Requirement: 1, 5_

- [x] 3. 实现进程启动监控
  - 使用可释放资源的 Windows 进程启动事件监听器。
  - 接入应用启动、配置开关和应用退出生命周期。
  - 命中后重新获取 PID 快照并执行安全过滤。
  - _Requirement: 2, 3_

- [x] 4. 扩展终止记录与自动终止路径
  - 增加终止来源字段并兼容旧日志。
  - 为黑名单自动终止提供独立路径，不受内存清理白名单误影响。
  - 记录成功、失败和跳过原因，并接入托盘通知。
  - _Requirement: 3, 4, 5_

- [x] 5. 增加黑名单界面
  - 在白名单页面加入独立黑名单卡片。
  - 增加名单维护、自动终止开关、首次开启确认和最近结果。
  - 保持 Fluent UI、响应式布局和中英文支持。
  - _Requirement: 1, 2, 4_

- [x] 6. 实现分析报告模型和展示
  - 将分析结果转换为报告摘要。
  - 保留上一次成功报告，失败时不清空旧报告。
  - 与现有页面级共享 ViewModel 一起保留导航切换状态。
  - _Requirement: 6_

- [x] 7. 实现分析对话服务与消息模型
  - 复用当前 LLM 档案和客户端。
  - 发送报告、最新进程快照和有限对话历史。
  - 解析回答和结构化清理计划；解析失败不得形成可执行计划。
  - _Requirement: 7, 8_

- [x] 8. 实现对话框和执行计划确认 UI
  - 增加对话框、消息列表、输入/取消/清空操作。
  - 展示清理计划、目标、风险、预计影响。
  - 所有改变系统状态的计划必须显式确认。
  - _Requirement: 7, 8, 9_

- [x] 9. 实现对话驱动清理执行器
  - 重新获取实时快照并重新应用所有安全过滤。
  - 对接 L1、L2 和 L3 现有服务。
  - L3 复用未保存工作提示和终止确认流程。
  - 写入对话来源的清理/终止历史。
  - _Requirement: 8, 9_

- [x] 10. 增加自动化测试
  - 覆盖黑名单标准化、持久化、保护名单和监听生命周期。
  - 覆盖报告保留、对话解析、计划确认和取消行为。
  - 覆盖自动终止不突破现有安全规则。
  - _Requirement: 1-9_

- [x] 11. 构建、回归验证和发布
  - 运行 Debug 构建和全部测试。
  - 启动编译产物进行黑名单、分析报告和对话人工验证。
  - 提交中文 commit 并推送 NAS。
  - _Requirement: 1-9_
