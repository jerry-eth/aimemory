# C 盘瘦身商业版实施任务清单

- [x] 1. 建立统一数据模型和安全边界
  - 扩展扫描结果、进度、跳过原因、操作报告和迁移状态模型。
  - 集中实现路径规范化、保护目录、reparse point、边界路径和当前应用目录检查。
  - 保持旧迁移日志 JSON 可读取。
  - _Requirement: 1, 2, 4, 5, 8_

- [x] 2. 收紧候选发现并实现可取消扫描
  - 仅发现安全的用户缓存、临时文件和明确的用户数据候选。
  - 去重、记录跳过原因，跳过 junction/symbolic link。
  - 增加 C 盘空间概览、扫描阶段、进度和取消。
  - 单项访问失败继续扫描并保留部分结果。
  - _Requirement: 1, 2, 7_

- [x] 3. 实现本地规则建议和 LLM 降级
  - 无 LLM 档案时生成可执行本地清理/迁移建议。
  - LLM 失败、超时或非法 JSON 时自动回退本地建议。
  - LLM 输入匿名化且不得影响安全决策。
  - _Requirement: 3_

- [x] 4. 实现安全回收站清理报告
  - 执行前再次验证路径和风险。
  - 只调用回收站 API，不允许永久删除降级。
  - 批量逐项返回成功、跳过、失败及释放量。
  - _Requirement: 4_

- [x] 5. 实现事务式跨盘迁移与回退
  - 目标盘、权限、空间、同盘/路径嵌套和占用检查。
  - robocopy 复制、文件数/字节数校验、junction 创建和可访问性确认。
  - 中断状态持久化，目标盘消失或 UAC 取消时保留数据副本。
  - 回退时不删除唯一数据副本，成功后再清理副本。
  - _Requirement: 5, 6, 8_

- [x] 6. 完善页面交互与可审计状态
  - 显示 C 盘概览、扫描状态、分类摘要、部分失败和取消状态。
  - 清理/迁移操作显示选中数量和预计空间，防止重复点击。
  - 展示迁移历史和未完成恢复入口。
  - _Requirement: 1, 4, 5, 7, 8_

- [x] 7. 测试、打包和交付审计
  - 补充服务、ViewModel、日志兼容和安全边界测试。
  - 运行全量测试、Release 自包含构建和 MSIX 打包。
  - 审计 API Key、Token、证书私钥和 artifacts 不进入 Git。
  - 提交中文 commit 并推送 GitHub；NetBird 可用时推送 NAS。
  - _Requirement: 9, 10_
