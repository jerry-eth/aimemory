## 1. L2 深度清理首用流程(重点)
- [ ] 主程序输出目录存在 `AiMemoryManager.ElevatedHelper.exe`(已自动确认,此处复核)
- [ ] 仪表盘点「深度清理」→ 弹出 UAC 授权框 → 授权后清理成功,显示「上次清理释放 X MB」
- [ ] 再次点「深度清理」→ **不再弹 UAC**(计划任务已注册,直接执行)
- [ ] UAC 弹窗点「否」→ 不崩溃,仪表盘显示「深度清理需要一次管理员授权,授权后不再询问(...)」
- [ ] 规则页开启「自动清理包含深度清理」并触发自动清理 → 同样只首次要授权
