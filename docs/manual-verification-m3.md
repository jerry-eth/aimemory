# M3 人工验证清单

自动化已覆盖:解决方案构建(0 警告 0 错误)、163 个测试(161 通过 + 2 个真实 LLM 端点集成测试,需设置 `AMM_TEST_LLM_KEY` 环境变量后才会运行)、Release 构建 0 警告 0 错误；Debug 启动 15 秒无异常冒烟、`git grep -E "sk-[A-Za-z0-9]{20,}"` 密钥扫描零命中、i18n 键对齐(zh-CN / en 各 192 键,无缺失)。
以下项涉及真实桌面交互 / 真实大模型服务 / 注册表 / 回收站与 Junction,无法无头验证,请人工走查。

## 1. L3 进程终止确认流(重点)
- [ ] 先打开记事本,输入任意内容但**不保存**(制造未保存状态)
- [ ] 进程页勾选该记事本进程 → 该行出现「高风险」标记(未保存工作提示)
- [ ] 再勾选 chrome(或其它占用大的进程)→ 点「结束所选」→ 弹出确认对话框,列出所选进程与风险提示
- [ ] 对话框中确认执行 → 进程被终止,仪表盘可见内存释放
- [ ] 「后悔药」恢复:在终止结果/历史中点恢复 → 记事本被重新打开(依赖 WMI 记录命令行;失败时按路径回退重开)

## 2. 防误杀(白名单)
- [ ] 白名单页把某进程(如 notepad)加入防误杀 → 进程页该进程的勾选框变为禁用
- [ ] 智能分析中若大模型给出该进程的 terminate 建议 → 该建议被过滤,不出现在建议卡片中

## 3. 分析页 terminate 建议执行
- [ ] 「智能分析」页拿到 terminate 建议 → 点执行 → **同样走 L3 确认对话框**(与进程页共用确认流),确认后才真正终止

## 4. 热键
- [ ] 按默认热键 **Ctrl+Shift+M** → 触发清理,有完成反馈
- [ ] 设置页把热键改为其它组合(如 Ctrl+Alt+K)→ 新键生效、旧键不再触发;重启应用后新键仍生效
- [ ] 占用降级:先用其它程序注册占住该组合键(或改成一个已被系统占用的组合)→ 应用不崩溃,静默降级(仅不注册热键),界面/日志有体现

## 5. 开机自启
- [ ] 未打包 Debug/发布目录运行时：设置页打开「开机自启」→ 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下出现 `AiMemoryManager` 值。
- [ ] MSIX 打包运行时：设置页打开「开机自启」→ `StartupTask` 状态变为 Enabled，关闭后变为 Disabled（不写入旧 Run 键）。
- [ ] (可选)重启资源管理器或注销重登 → 应用随系统启动。
- 注意：必须用编译产物的 exe 或已安装 MSIX 验证自启，不能用 `dotnet run` —— 后者 `Environment.ProcessPath` 指向 `dotnet.exe`。

## 6. 通知开关
- [ ] 关闭「清理完成通知」→ 执行一次清理 → **不弹**系统通知
- [ ] 打开开关 → 再执行一次清理 → 弹出「清理完成,释放 X MB」通知

## 7. C 盘瘦身(重点)
- [ ] 打开 C 盘瘦身页 → 扫描 → 结果按大小排序合理(大项在前)
- [ ] 点 LLM 分析(DeepSeek 档案)→ 出现瘦身建议(迁移 / 删除 / 保留)及理由
- [ ] 勾选 Temp 类项目执行删除 → 文件**进入回收站**,在回收站可见且可还原
- [ ] 选一个小文件夹迁移到 D 盘 → 迁移后原位置变为 Junction;用资源管理器打开原路径**无感**(直接看到内容)
- [ ] 执行回退 → 文件搬回原位,Junction 移除
- [ ] 占用检测:迁移前先打开该文件夹内的程序/文件使其被占用 → 迁移被拦截并给出占用提示
- [ ] 注意:迁移源目录的删除为**永久删除**(对话框有明确警告),仅删除操作走回收站 —— 属预期设计

## 8. 历史
- [ ] 分别执行 L1(一键清理)、L2(深度清理)、L3(进程终止)→ 仪表盘历史卡均出现对应记录(触发方式:手动 / 分析 等)
- [ ] 历史超过 100 条后自动截断,只保留最近 100 条

## 9. 密钥与真实端点(需自备 API Key)
- [ ] 用文本编辑器打开数据目录下 `llm-profiles.json` → API Key 为 DPAPI 密文,**无明文**
- [ ] 设置环境变量 `AMM_TEST_LLM_KEY` 为自己的 DeepSeek 密钥后,运行 `dotnet test` → 2 个真实端点集成测试由跳过变为通过(密钥仅经环境变量传入,不要写入任何文件)
