AI 内存管家隐私政策

生效日期:2026 年 8 月 21 日  |  版本:1.0

1. 概述

AI 内存管家是 Windows 桌面工具,用于显示本机内存、进程和磁盘状态,并根据用户明确操作执行内存清理、文件清理、迁移或进程终止。软件不提供云端账户,不内置开发者遥测服务,不出售用户数据。

2. 本地数据

默认情况下,设置、白名单、黑名单、提示词、分析缓存、清理历史和迁移记录保存在本机用户数据目录。API Key 等敏感配置使用 Windows DPAPI 保护。软件不会因为启动、扫描、清理或升级而自动上传这些数据。

3. 可选大模型数据传输(BYOK)

只有当用户主动配置大模型档案并点击分析或发送对话时,软件才会把完成请求所需的最小数据发送到用户选择的 Base URL。可能包含:

  • 当前内存和磁盘占用摘要;
  • 进程名称、PID、路径和工作集大小;
  • 用户输入的对话内容;
  • 当前分析报告和有限的对话历史。

数据只发送到用户配置的端点(例如用户自己的 OpenAI 兼容服务或本机 Ollama),软件不会把这些数据转发到开发者服务器。第三方端点的数据处理、留存和跨境传输受其隐私政策及服务条款约束。

4. 完整版与 Microsoft Store 版差异

  • 完整版/便携版:可包含高级待机列表清理,需要用户确认,并可能触发 UAC 或使用受保护的计划任务。
  • Store 兼容版:不声明 allowElevation,不安装最高权限计划任务,不包含自动启动扩展;高级待机列表清理会隐藏或拒绝,自动规则自动降级到普通清理。
  • 两个版本都保留普通内存清理、C 盘扫描、回收站清理、迁移、回退和进程保护逻辑;高风险操作仍需用户确认。

5. 权限与危险操作

部分工作集清理、文件迁移、回收站操作或进程操作可能受到 Windows 权限限制。软件在改变系统状态前显示确认界面;UAC 被取消或权限不足时,操作会失败并保留原有数据。软件不会自动终止系统关键进程、当前前台保护进程或白名单进程。

6. 用户删除数据

用户可以退出软件后删除应用数据目录,以清除本地配置、缓存、历史和迁移记录。删除前应确认没有正在进行的迁移或清理任务,并保留希望继续使用的配置备份。
